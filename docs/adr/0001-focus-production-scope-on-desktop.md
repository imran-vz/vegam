# Focus Production Scope on Desktop

Vegam's next production milestone targets Windows, Linux, and macOS only. Mobile remains a future requirement, but pausing Android and iOS work keeps transfer reliability, packaging, update, and support decisions focused on one production surface before mobile constraints return. Mobile-specific code, dependencies, plugins, and build targets should be removed from the v1 production path, but hard-to-recover mobile knowledge should be preserved in documentation for the later Mobile Release.
